## A.错误的动机和高昂的代价

### 一、错误的动机与高价收购

#### 1.1 核心立场

伯克希尔的收购决策目标是**实现真正经济利益的最大化**，而非管理版图或会计报告数字的最大化。

> 💡 宁可以每股 X 的价格购买优秀目标公司 10% 的股权，也不愿以 2X 的价格购买其 100% 的股权。

#### 1.2 高价收购背后的三个真实原因

| #    | 原因         | 说明                                                         |
| ---- | ------------ | ------------------------------------------------------------ |
| 1    | **动物精神** | 企业领导者精力旺盛，渴望激情与挑战，收购行为满足其情感需求   |
| 2    | **规模崇拜** | 管理层薪酬以公司规模衡量，而非盈利能力；排名标准是销售规模   |
| 3    | **童话幻觉** | 管理层深信自己的"管理之吻"能将"癞蛤蟆"（劣质公司）变为"王子"（优质公司） |

> ⚠️ **癞蛤蟆比喻**：投资者可随时在市场上以现行市价买入"癞蛤蟆"。若以两倍价格换取"亲吻癞蛤蟆的权力"，这些亲吻必须具备真正的魔力——但现实中大多数亲吻并未带来奇迹。即便公司后院已挤满癞蛤蟆，许多管理层仍对自己的"亲吻潜能"保持沉着的自信。

------

### 二、两类杰出的收购

#### 2.1 第一类：适应通货膨胀的公司

被收购公司须同时满足以下两个特征：

1. **容易提价的能力**：即便需求平平、产能未充分开工，也无惧提价带来的市场份额或销售量下降。
2. **低增量资本扩容能力**：只需投入少量增量资本，即可容纳因通胀带来的业务量大幅增加。

> ⚠️ 同时符合两个特征的企业非常稀少，且竞争日趋白热化，已到本末倒置的不合算程度。

#### 2.2 第二类：由管理明星运营的公司

这类管理者能识别出伪装成癞蛤蟆的优秀王子，并具备"脱去伪装"的能力。代表人物包括：

- 西北实业的**本·海涅曼**
- 特利丹的**亨利·辛格尔顿**
- 国家服务工业公司的**欧文·扎班**
- 大都会公司的**汤姆·墨菲**（真正"能用一分钱买两分货"的管理人才，兼跨两类）

> 💡 这些冠军管理者近年来较少再进行并购，反而常常发现**回购自家股份**是公司资本最有效的运用方式。

### 三、股票发行用于收购的危害

#### 3.1 核心原则

**伯克希尔发行股票的基本原则**：除非取得的内在价值至少与付出的代价相等，否则不发行股票。

#### 3.2 管理层为发行新股常用的三个借口

| 借口                       | 反驳                                                         |
| -------------------------- | ------------------------------------------------------------ |
| "收购的公司未来将更值钱"   | 被卖掉的老公司权益同样更值钱；价值不平衡在双方估值翻番后依然存在 |
| "我们必须成长"             | 发行新股稀释了现有股东对优质资产（如禧诗糖果、国民保险）的持股比例 |
| "我们已将股票比例降至最低" | 如果发行100%新股有害，发行51%同样造成等比例伤害              |

> 💡 **农庄比喻**：你家拥有120英亩农庄，邻居60英亩。以50:50合并后，管理面积扩大至180英亩，但你家权益缩水25%。那些想花股东的钱扩大版图的管理层，应该考虑去政府部门谋职。

#### 3.3 以低估货币购买足值资产的恶性逻辑

当买家股票市价仅为内在价值的一半时：

- 整体出售公司时，可谈判得到**完整内在价值**的出售价
- 但发行部分股票时，只能得到**市场标价**，无法得到更多

> ⚠️ 结果：收购方用低估的货币（市场股价）购买足值的财产，实际付出 2 元却得到 1 元。**不应用被估值成铅的金子，去购买被估值成金子的金子。**

### 四、三种避免价值破坏的合并方式

| 方式                        | 说明                                                       | 典型案例                                                 |
| --------------------------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| **企业对企业等值合并**      | 双方以真正内在价值进行等值交换，一视同仁                   | 伯克希尔与蓝筹印花公司的合并计划；达特工业与卡夫食品合并 |
| **收购方股票市价≥内在价值** | 以股票作为货币不损害收购方股东                             | 1965—1969年间发生较多；1970年后大多数结果相反            |
| **收购后回购等量股票**      | 将"股票对股票"并购有效转化为"现金对股票"并购，修复先前损失 | 伯克希尔所推荐的弥补方式                                 |

### 五、并购中的语言措辞陷阱

#### 5.1 "稀释"的误用

- 管理层常以每股净利润（EPS）的稀释与否作为并购合理性的唯一判据，存在重大危险。
- **正确做法**：以**内在价值**为标准衡量稀释与否，而非仅看账面净资产或当期EPS。

> 许多并购在 EPS 意义上"未稀释"，却即刻损害了收购方的内在价值；另有一些并购稀释了近期 EPS，却实际提升了长期价值。

#### 5.2 收购语言的不对称

| 常用表述（不准确） | 更准确的表述                                      |
| ------------------ | ------------------------------------------------- |
| "A公司收购B公司"   | "出售部分A公司以收购B公司"                        |
| "B公司被卖给A公司" | "B公司股东收到部分A公司股票，用以交换其B公司股票" |

> 💡 在一笔交易中，**你所付出的与你所获得的同等重要**。

### 六、不负责任的新股发行：双重打击效应

```
第一重打击：并购直接引发的内在价值损失
第二重打击：股票市场对稀释后企业价值的向下理性修正
```

- 管理层一旦显示出对股东利益的迟钝，权益持有人将长期承受价格/价值比的痛苦。
- 即便管理层保证"仅此一次，下不为例"，市场的反应犹如在餐馆沙拉中发现虫子——无论解释如何，需求依然下降。

> **反之亦然**：当管理层证明其不愿发行新股损害股东利益时，公司将在股市获得与内在价值相应的最高估值。

### 七、伯克希尔的并购原则与实践

#### 7.1 优先使用现金收购

伯克希尔从 1967 年收购国民保险公司起，历次重要收购均使用现金：

- 禧诗糖果
- 《水牛城新闻报》
- 思考特·费泽公司
- 盖可保险

> 💡 **棒球比喻**：我们的花名册上已载满"击出 0.380 的击球手"式优秀成员。用其中一位换取 0.350 的新成员，并不合算。

#### 7.2 理想收购对象的三个特征

| 特征               | 说明                           |
| ------------------ | ------------------------------ |
| ① **看得懂**       | 业务模式在我们的能力圈范围之内 |
| ② **经济基础稳健** | 具有良好且持续的盈利能力       |
| ③ **优秀管理层**   | 由我们喜欢、尊重、信任的人运营 |

#### 7.3 警惕管理层的"动物精神"

- CEO 获得今日地位，往往正是因为其丰富的动物精神与自负秉性；达到顶峰后这些特点不会消失。
- 被顾问鼓动进行并购，对本就雄心勃勃的 CEO 而言，鼓励是多余的。
- 大型收购的受益方通常是：被收购方股东、收购方管理层、投资银行家与职业顾问——**而非收购方公司的股东**。

> ⚠️ 约翰·梅德林评价道："够了，你们就是在玩反向的连锁信游戏。"

------

### 八、资产配置与长期价值

- 管理层的资产配置能力对企业长期价值有**巨大影响**。
- 优秀企业度过早期后，产生的现金远超内部消耗所需；CEO 面临如何分配盈余资本的考验。
- 伯克希尔拒绝了许多可提升近期 EPS 但降低每股内在价值的并购机会。

> 💡 **格雷茨基法则**："到冰球将要去的地方，而不是到冰球所在的地方。"
