### 三、六大技巧详解

#### 3.1 固定资产记减至负10亿美元

```markdown
操作逻辑：
- 传统做法：厂房设备减值至$1 → 降低折旧费用
- "创新"做法：减值至 -$10亿 → 折旧变"增值"

计算示例：
- 原折旧费用：$4,700万/年
- 新"增值"收益：5% × $10亿 = $5,000万/年
- 净提升：$4,700万 + $5,000万 = **$9,700万/年**
```

> ⚠️ **逻辑漏洞**：资产为负值违背会计基本准则，"增值"实为账面游戏。

#### 3.2 普通股面值减少到$0.01

- **目的**：为股票期权薪酬方案提供操作空间
- **法律备注**：因在弗吉尼亚州重新注册，"声明价值"≠"面值"

#### 3.3 用股票期权支付所有薪酬 💡

| 优势维度       | 具体效果                                               |
| -------------- | ------------------------------------------------------ |
| **成本消除**   | 工资账单归零，年节省 **$2.5亿**                        |
| **员工激励**   | 每股盈利"提升"→股价>行权价$50→期权价值远超现金薪酬     |
| **账面利润**   | 行权时每股产生$49.99所得，计入**资本盈余**（非损益表） |
| **现金流逆转** | 从年流出$2.5亿工资 → 年流入$2.5亿行权资金              |

```python
# 期权行权现金流模拟（伪代码）
def cash_flow_impact(shares_exercised, exercise_price, par_value):
    cash_inflow = shares_exercised * exercise_price
    capital_surplus = shares_exercised * (exercise_price - par_value)
    return {
        "现金流入": cash_inflow,
        "资本盈余增加": capital_surplus,
        "损益表影响": "无"  # ⚠️ 关键：利润不体现在当期收益
    }
```

> 💡 **讽刺点**：通过会计分类将真实现金流包装为"额外利润"。

#### 3.4 将存货记为$1

```markdown
操作流程：
1. 期初存货估值：$1（无论实际价值）
2. 年内销售：按市场价确认收入 → 产生"超高毛利"
3. 年末调整：从应急储备金中提取资金"补平"存货减值

声称效果：
- 规避存货跌价损失
- 年度盈利提升 ≥ $1.5亿
- 储备金支出 ≈ 盈利提升额 → 账面"自洽"
```

> ⚠️ **审计备注**：应收账款与现金未同步"象征化"，因审计规则要求回收款计入资本盈余而非当期收益。

#### 3.5 零息债券置换优先股

| 置换要素      | 原方案（优先股） | 新方案（零息债券）            |
| ------------- | ---------------- | ----------------------------- |
| 面值          | 每股优先股       | $300/张债券                   |
| 赎回方式      | -                | 抽签+50%面值+10年期等额赎回   |
| 年度赎回额    | -                | $1.08亿面值 → 实际支付$0.54亿 |
| 年度"利润"    | -                | **$0.54亿**（赎回差价）       |
| 股息/利息支出 | $2,500万/年      | $0（零息）                    |
| 净收益提升    | -                | **$7,900万/年**               |

#### 3.6 建立$10亿应急储备金

```markdown
功能定位：
✅ 吸收存货$1入账产生的年度减值
✅ "覆盖"任何潜在经营亏损
✅ 维持方案表面可持续性

补充机制：
- 来源：股票期权行权产生的资本盈余（≥$2.5亿/年）
- 流向：应急储备金
- 效果：储备金"永不枯竭"的账面幻觉
```

> ⚠️ **本质**：用资产负债表科目间的转移掩盖真实盈利能力。

## B. 标准的设定

#### 1.1 安达信的立场转变

**安达信会计事务所**（Arthur Andersen）曾是审计行业的权威标杆。其内部由行业精英组成的**专业标准小组（PSG）** 长期坚持财务报表必须如实编制。

**1992年 PSG 的核心立场：**

- 坚持将**股票期权成本列为费用**
- 不向客户压力妥协

然而，受另一批"呼风唤雨"合伙人的推动，PSG 立场发生 **180° 大转弯**——这些合伙人深知客户真正想要的是更高的账面盈利。

> 众多 CEO 同样反对期权费用化，原因在于：一旦落实，他们渴望已久的大额期权授予将大幅缩水。

---

#### 1.2 FASB 的抗争与妥协

| 事件                                    | 结果                        |
| --------------------------------------- | --------------------------- |
| FASB 以 **7:0** 投票通过期权费用化      | 独立标准确立                |
| 大型会计事务所与众多 CEO 涌入华盛顿游说 | 向参议院施压，试图废除 FASB |
| 参议院以 **88:9** 投票反对期权费用化    | ⚠️ 标准独立性严重受损        |
| 证监会主席阿瑟·莱维特迫于压力妥协       | 事后坦承为任内最大遗憾      |

💡 相关细节可参考莱维特著作《**挑战华尔街**》。

游说资金本属于被欺诈公司的股东，却被用于政治献金——**这不应是文明社会应有的现象**。

---

#### 1.3 "荣誉系统"的败局

面对参议院威胁，FASB 最终退缩，转而推行**"荣誉系统"**：

- 声明期权费用化为**优先建议**
- 但允许公司依自身情况**选择忽略**此成本

**结果：**

| 标普500大公司 | 选择                             |
| ------------- | -------------------------------- |
| **498家**     | 采用较不理想的方法，美化账面盈余 |
| **2家**       | 遵循费用化原则                   |

> FASB 得到了"荣誉"，而 CEO 们赢得了整个系统。

---

#### 1.4 影响与后果

参议院被收买、证监会失守之后，美国企业界意识到：**在会计处理上可以为所欲为**。

- 一个以**"盈利报告至上"**为核心的新时代由此开启
- 部分著名审计师在背后推波助澜
- 放肆的财务行为迅速成为**大泡沫时代**的助燃剂



## C. 股票期权

#### 1.1 核心争议：期权是否应计为成本？

在公司管理层和会计师的种种失真行为中，**股票期权的会计处理**是最令人震惊的问题。数十年来，众多企业持续与会计规则制定者博弈，试图避免将期权成本反映在公司账面上。

管理层的常见借口如下：

| 借口                                 | 反驳                                           |
| ------------------------------------ | ---------------------------------------------- |
| 期权难以估值，成本应忽略             | 不精确不等于不存在，折旧、坏账同样无法精确量化 |
| 费用化会伤害初创公司                 | 成本客观存在，不记录只是转嫁给股东             |
| "价外"期权发行时没有价值             | 巴菲特表示愿意收购任何管理层的"无价值"期权     |
| 期权"不来自公司金库"，非现金即非成本 | 以期权支付广告费，难道广告成本就消失了？       |

> 💡 巴菲特的反驳：若"无现金即无成本"成立，盖可保险可用伯克希尔期权支付1.9亿美元广告费——没有人会认为这笔广告成本不存在。

---

#### 1.2 通用再保险收购案：会计缺陷的实证

伯克希尔收购**通用再保险**一案，清晰暴露了现行会计准则的缺陷。

**关键数据（见股东委托书第60页）：**

- 收入预测表中，报酬成本一项上升 **6300万美元**
- 原因：将原有**期权激励计划**改为**现金激励计划**

| 对比维度     | 期权激励计划   | 现金激励计划 |
| ------------ | -------------- | ------------ |
| 激励基础     | 公司股票价格   | 个人工作业绩 |
| 经济效果     | 相同           | 相同         |
| 会计处理     | **不计入成本** | **计入成本** |
| 账面盈利影响 | 虚高           | 真实反映     |

⚠️ 两种计划经济效果完全相同，却产生截然不同的会计结果——这正是"爱丽丝漫游仙境"式的会计失真。

---

#### 1.3 期权成本的估值逻辑

**期权并非难以估值**，巴菲特的核心论点：

1. 不精确不等于不应确认——折旧率、坏账准备同样不精确，但从未被忽略
2. 带限制条件的期权增加了估值难度，但**不消除估值的可能性**
3. 相比估算747飞机折旧率，给期权定价的把握**更大**

> 如果某位 CEO 声称新发期权"几乎没有价值"，巴菲特的回应是：**请把它们发给伯克希尔。**

---

#### 1.4 员工期权 vs. 公开市场期权

针对"员工期权价值低于市场期权"的说法，巴菲特的分析：

| 论点                           | 事实                                        |
| ------------------------------ | ------------------------------------------- |
| 员工期权可能失效，损害较小     | 员工期权经常被**重新定价**，实际成本更高    |
| 公司可获得员工行权时的免税额度 | 重新定价的对冲使整体成本不减反增            |
| 不可转让期权对员工价值更低     | 对员工价值低 ≠ 对公司成本低（如专用公务车） |

**巴菲特的调整实践：**

- 近年来，期权盈利调整常将每股盈利减少 **5%～10%**
- 调整幅度有时大到影响投资决策，进而调整买卖价格

#### 1.7 合理的期权设计原则

巴菲特与芒格并不反对使用期权，而是主张**合理设计**：

1. 具有**合理的行权价格**
2. 行权价格应随公司**留存利润**进行相应调整
3. **禁止**获得期权后立刻抛售股票

> 💡 对于能够激励经理人的奖励措施，无论现金还是期权，均举双手赞成。关键在于：**如实记录成本，而非掩盖成本。**

---

#### 1.8 结论

将股票期权处理为无成本，是 CEO 们夸大盈利最重要的会计手法。其本质是：

- **会计原则给了管理层选择权**：支付报酬且计成本，或支付报酬但忽略成本
- CEO 们深知，一旦如实记录，其薪酬将被理性压缩，行权套现价格也将下降
- 用于游说的资金，**按理说属于股东，而非管理层**
